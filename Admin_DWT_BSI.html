Data Submission Pemetaan

Unggah berkas CSV hasil pengumpulan pemetaan tim (ekspor dari Google Sheet pengumpul). Data hanya diproses di peramban Anda, tidak dikirim ke mana pun.

Klik untuk memilih, atau seret berkas CSV ke sini

Format kolom mengikuti keluaran Kanvas: timestamp, bm, cabang, anggota, peran, skill, will, kuadran, dan seterusnya.

Analisis Pemetaan

Potret seluruh KCP dari pemetaan para Branch Manager. Gunakan filter untuk menelaah per KCP, posisi, atau kuadran.

Muat data dulu di tab Data.

Report Pemetaan KCP

Potret satu KCP beserta masukan intervensi untuk tiap orang sesuai posisi Skill dan Will-nya.

Muat data dulu di tab Data.

Report Individu

Satu report per Branch Manager, lengkap dengan pemetaan tim, cermin diri, dan intervensi. Cetak massal akan menghasilkan PDF yang tetap terpisah per orang.

Tiap BM dimulai di halaman baru.
Muat data dulu di tab Data.

Live Scoring CPI

Branch Coach menilai tiap peserta sepanjang hari. Input bisa langsung di sini, atau diketik admin dari lembar cetak Coach. CPI dihitung otomatis mengikuti bobot proposal: Classical 20, Simulasi 25, Case Study 25, Games 15, Assignment 15.

Roster Peserta

Isi manual, atau unggah CSV roster berisi kolom: nomor, nama, nip, kcp, kota, provinsi, kelompok.
Live sync lintas perangkat butuh Firebase, lihat catatan di bawah.

Tabel Penilaian

Skor mentah skala 0 sampai 100 untuk Classical, Simulasi, Case Study, Games, Assignment. Pre dan Post bersifat informatif untuk Learning Gain.
Belum ada peserta. Tambah manual, unggah roster, atau muat data contoh di tab Data.

Catatan Live Sync (Firebase)

Agar beberapa Branch Coach menilai bersamaan dan papan skor admin ikut hidup, isi konfigurasi Firebase di bawah. Bila dikosongkan, konsol tetap berjalan penuh secara lokal di satu perangkat.
